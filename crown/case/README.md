# MeteMatik Crown — 3D-printed case (no battery) v3.4

For the **Elecrow CrowPanel Advance 2.8" ESP32-S3 (V1.2)**. Tested print.

| File | Part |
|---|---|
| `MeteMatik_CP28_v3.4_front.stl` | Front layer (screen window) |
| `MeteMatik_CP28_v3.4_back.stl` | Back layer (built-in 32° stand, USB opening) |
| `MeteMatik_CP28_v3.4_foot.stl` | Small foot |
| `MeteMatik_CP28_case_v3.4.step` | Full model (for editing) |

**Screws:** 4 × M3×16, DIN 7985 (pan head, cross), from the back.

**Printing:** PLA or PETG. Front layer face-down on the bed. Back layer with the open side on the bed. The USB-C port used for power is the one marked **USB**; RESET is covered, BOOT can be reached with a paper clip.

A battery version (switch + battery gauge, soldering required) will be published separately.

# MeteMatik Crown — 3D baskı kutu (pilsiz) v3.4

**Elecrow CrowPanel Advance 2.8" ESP32-S3 (V1.2)** için. Basılıp denendi.

| Dosya | Parça |
|---|---|
| `MeteMatik_CP28_v3.4_front.stl` | Ön katman (ekran penceresi) |
| `MeteMatik_CP28_v3.4_back.stl` | Arka katman (32° ayak, USB ağzı) |
| `MeteMatik_CP28_v3.4_foot.stl` | Küçük ayak |
| `MeteMatik_CP28_case_v3.4.step` | Tüm model (düzenlemek için) |

**Vida:** 4 adet M3×16, DIN 7985 (yıldız, silindir baş), arkadan.

**Baskı:** PLA veya PETG. Ön katman yüzü aşağı; arka katman açık tarafı tablaya. Güç için **USB** yazan Type-C girişi kullanılır; RESET kapalı, BOOT'a ataçla ulaşılır.

Pilli sürüm (anahtar + pil ölçer, lehim gerekir) ayrıca yayınlanacak.
