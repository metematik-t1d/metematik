Elecrow CrowPanel Advance 2.8" ESP32-S3 (V1.2) · yazılım / firmware 4.0.6

Tıbbi cihaz değildir. Tedavi kararları için resmi CGM cihazınızı / uygulamanızı esas alın. Asıl CGM alarmlarınızı kapatmayın. Garanti verilmez.
Not a medical device. Rely on your official CGM device / app for treatment decisions. Do not turn off your CGM alarms. No warranty.

Türkçe

  1. Bilgisayarda Chrome veya Edge kullanın (telefonda ve Safari'de çalışmaz).
  2. Kartı, üzerinde USB yazan girişten, veri taşıyan bir USB-C kabloyla bilgisayara takın.
  3. Aşağıdaki Connect düğmesine basın, listeden kartı seçin (USB JTAG/serial veya ESP32-S3), sonra Install MeteMatik Crown'a basın.
  4. İlk kurulumda "cihazı sil" seçeneğini işaretleyebilirsiniz. Güncellemede işaretlemeyin: ayarlarınız ve fotoğraflarınız kalır.
  5. Bitince cihaz kendiliğinden yeniden başlar. Başlamazsa USB kablosunu çıkarıp tekrar takın.

🎬 Video: yazılım yükleme · montaj · kurulum ve kullanım · kurulum rehberi

Kart listede yoksa: veri taşıyan başka bir USB-C kablo deneyin. Yine görünmezse kablo çıkarken kartın BOOT tuşunu (kutudaysa bir ataçla) basılı tutun, kabloyu takın, BOOT'u bırakın ve tekrar deneyin.

English

  1. Use Chrome or Edge on a computer (does not work on phones or Safari).
  2. Connect the board's port marked USB with a USB-C cable that carries data.
  3. Press the Connect button below, pick the board (USB JTAG/serial or ESP32-S3), then press Install MeteMatik Crown.
  4. For a first install you may tick "erase device". For an update leave it unticked: your settings and photos are kept.
  5. When finished the device restarts by itself. If it does not, unplug the USB cable and plug it in again.

🎬 Video: how to install · assembly · setup & tour · setup guide

Board not listed? Try another USB-C cable that carries data. If it still does not appear, unplug the cable, hold the board's BOOT button (with a paper clip if it is in the case), plug the cable in, release BOOT and try again.
